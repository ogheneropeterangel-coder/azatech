# AZATECH GLOBAL SUPPLY CHAIN LIMITED

Premium corporate website for Azatech Global Supply Chain Limited — a Nigeria-based company connecting organizations with medical equipment, laboratory technology, specialized technology solutions, sourcing, supply-chain coordination, logistics and after-sales support.

**CONNECT • MOVE • DELIVER**

## Tech Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4
- Framer Motion (animations)
- React Router v7 (routing)
- Lucide React (icons)

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home — hero carousel, capabilities, equipment, supply chain process, industries, CTA |
| `/about` | About — approach, vision, mission, values |
| `/equipment` | Medical equipment & diagnostic technology catalogue |
| `/solutions` | Solutions — sourcing, laboratory, medical tech, global supply, logistics, after-sales |
| `/supply-chain` | Supply chain process and details |
| `/industries` | Industries served |
| `/contact` | Contact details + enquiry form |
| `/request-quote` | Request a quote form |

## Development

```bash
npm install
npm run dev        # start dev server
npm run build      # production build
npm run preview    # preview production build
npm run lint       # run oxlint
```

## Deployment (Vercel)

This is a standard Vite + React SPA. Deploy by importing this GitHub repository into Vercel — no special config is needed. Vercel automatically detects the Vite build (build command `npm run build`, output directory `dist`).
